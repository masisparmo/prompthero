⚙️ Pengaturan API Key

Prompt Hero menggunakan AI dari Google Gemini dan Groq Llama untuk mengevaluasi prompt kamu. Agar aplikasi bisa berjalan dengan stabil, kamu perlu memasukkan API Key milikmu sendiri. Tenang, keduanya bisa didapatkan secara GRATIS!

⚡ Gemini (Google)

Cara mendapatkan API Key Gratis:
1. Kunjungi Google AI Studio.
2. Login dengan akun Google kamu.
3. Klik tombol "Get API Key" lalu "Create API key".
4. Salin kunci (yang diawali dengan AIzaSy...) dan tempel di kotak bawah.

🚀 Llama (Groq)

Cara mendapatkan API Key Gratis:
1. Kunjungi Groq Console.
2. Login atau daftar akun baru.
3. Klik tombol "Create API Key".
4. Salin kunci (yang diawali dengan gsk_...) dan tempel di kotak bawah.
